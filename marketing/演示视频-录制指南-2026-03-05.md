## 🎯 目标
录制一个5-8分钟的演示视频，展示Anki学习卡片生成器的核心功能。

## 📋 准备工作

### 1. 环境准备
```bash
# 启动Web服务
cd /root/.openclaw/workspace/anki-card-generator
./start_web.sh

# 确认服务运行
curl http://localhost:5000/health
```

### 2. 素材准备
- ✅ 示例PDF：`examples/demo_ai_textbook.pdf`（11页，已有）
- ✅ 生成的卡片：`output/demo_ai_textbook_*.apkg`（已有）
- ⏳ Anki软件：需要在录制机器上安装
- ⏳ BGM：无版权音乐（可选）

### 3. 录屏工具
- **Linux**: OBS Studio / SimpleScreenRecorder
- **Mac**: QuickTime / OBS Studio
- **Windows**: OBS Studio / 系统自带录屏
