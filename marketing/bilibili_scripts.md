```python
result = parser.parse()
```

2. 卡片生成：
```python
generator = AnkiCardGenerator()
cards = generator.generate_from_keypoints(key_points)
```

3. 导出Anki：
```python
export_cards(cards, deck_name, output_format='apkg')
```

就这么简单！
