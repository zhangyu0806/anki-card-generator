# 示例文件和演示

## 示例PDF文件

你可以使用任何PDF教材进行测试。以下是推荐的测试文件类型：

1. **教材类** - 大学/考研教材
2. **技术文档** - 编程教程、API文档
3. **考试资料** - 考证/资格考试教材

## 使用方法

### 命令行

```bash
# 激活虚拟环境
source venv/bin/activate

# 生成Anki卡片
python anki_gen.py your_textbook.pdf \
    --deck-name "我的教材" \
    --types qa,cloze,concept \
    --format apkg
```

### Web界面

```bash
# 启动Web服务
cd web
python app.py

# 浏览器访问
http://localhost:5000
```
